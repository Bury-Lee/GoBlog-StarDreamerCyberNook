GoBlog-StarDreamerCyberNook 架构(单进程 · 微服务化)

一个 main 进程即统一宿主(GoTenon 内核):按 setting.yaml 装配 博客网关 + 11 个 gRPC 微服务组件 · 共享 global.DB 单连接池(dbStandalone 可独立库)

单一配置源

  • • setting.yaml:host.enable / components / services
  • • components 支持简写 svc: true 与完整 {enabled, config}
  • • 各服务地址、数据库、JWT、AI、邮件均从 setting 派生
  • • 环境变量 SVC_<KEY> 可覆盖服务地址

数据访问(共享优先)

  • • 宿主初始化唯一 global.DB(池 10/100/1h、读写分离)
  • • 微服务默认复用该句柄 → 全进程单连接池(SQLite 不再多池争锁)
  • • components.<svc>.config.dbStandalone=true → pkg/dbx 自建独立库
  • • common.ListQuery 显式接收各服务 db,不再硬编码 global.DB

进程内微服务

  • • 一个 main 进程 = 统一宿主(GoTenon 内核)
  • • 11 个 gRPC 服务 9210~9296;services/*/cmd 可独立部署
  • • 博客网关经 gRPC(sd:/// round_robin)调用服务
  • • 失败回滚 / 逆序停机 / panic 兜底(含堆栈)

可观测与热配置

  • • /api/t/config:运行时查看/修改配置(AI/ES 等)
  • • 命令行 -db/-es/-search/-create-user/-v 在 main 启动前执行
  • • 博客 HTTP :8080;静态资源与前端同进程托管
  • • 定时任务(Redis 计数回写、清理)在网关;鉴权角色 Redis 缓存
